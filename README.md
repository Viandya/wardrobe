# Гардероб

Сайт для сборки капсульных образов: загружаешь фото вещей, у них автоматически убирается фон и определяются цвета, а приложение собирает из них коллажи-капсулы. Гардероб хранится в облаке и одинаковый на телефоне и на ноутбуке.

## Что нужно один раз настроить

Всего два сервиса, оба бесплатные: **Supabase** — база и хранилище фотографий, **Vercel** (или GitHub Pages) — сам сайт. Программировать не нужно, только копировать и вставлять.

### Шаг 1. Supabase — база данных

1. Зайди на **supabase.com**, зарегистрируйся, нажми **New project**.
2. Придумай название и пароль базы, регион выбери **Frankfurt** — он ближе всего к Цюриху. Проект создаётся 2–3 минуты.
3. Открой слева **SQL Editor** → **New query**. Скопируй туда целиком содержимое файла `supabase/schema.sql` из этой папки и нажми **Run**. Это создаст таблицы, права доступа и хранилище для картинок. Внизу должно появиться `Success`.
4. Открой **Project Settings** (шестерёнка) → **API**. Оттуда понадобятся два значения:
   - **Project URL** — вида `https://abcdefgh.supabase.co`
   - **anon public** ключ — длинная строка, начинается с `eyJ`

> Ключ `anon` можно спокойно публиковать: сам по себе он ничего не открывает. Доступ к данным закрыт правилами из `schema.sql` — каждый видит только свои вещи. **Никогда не публикуй** второй ключ, `service_role`.

### Шаг 2. Проверка на своём компьютере (можно пропустить)

Нужен установленный [Node.js](https://nodejs.org). В папке проекта:

```bash
cp .env.example .env      # затем впиши в .env свои URL и ключ
npm install
npm run dev
```

Откроется `http://localhost:5173`. Введи почту, получишь письмо со ссылкой, перейдёшь по ней — попадёшь в пустой гардероб.

### Шаг 3. GitHub

1. Создай аккаунт на **github.com**, если его нет.
2. Нажми **New repository**, назови, например, `wardrobe`, оставь **Private** или **Public** — на твой выбор.
3. На странице пустого репозитория нажми **uploading an existing file** и перетащи туда содержимое этой папки (все файлы и папки, кроме `node_modules`, если ты запускала шаг 2). Нажми **Commit changes**.

Файл `.env` при этом не загружай — он в `.gitignore`, ключи будут задаваться в настройках хостинга.

### Шаг 4. Публикация

**Вариант А — Vercel (рекомендую, проще и быстрее).**

1. На **vercel.com** войди через GitHub.
2. **Add New → Project**, выбери свой репозиторий, нажми **Import**.
3. В разделе **Environment Variables** добавь две переменные:
   - `VITE_SUPABASE_URL` — Project URL из шага 1
   - `VITE_SUPABASE_ANON_KEY` — ключ anon
4. **Deploy**. Через минуту получишь адрес вида `wardrobe-xyz.vercel.app`.

**Вариант Б — GitHub Pages.** В репозитории: **Settings → Pages → Source: GitHub Actions**, затем **Settings → Secrets and variables → Actions → Variables** и добавь те же две переменные. Дальше публикация пойдёт сама при каждом изменении — за это отвечает `.github/workflows/deploy.yml`.

### Шаг 5. Последний штрих в Supabase

Открой **Authentication → URL Configuration** и впиши адрес своего сайта в **Site URL** (например, `https://wardrobe-xyz.vercel.app`), а также добавь его в **Redirect URLs**. Без этого ссылка из письма будет возвращать на localhost.

Готово. Заходи с телефона по тому же адресу, введи ту же почту — увидишь тот же гардероб. Ярлык на домашний экран: в Safari «Поделиться» → «На экран "Домой"», сайт откроется как приложение.

## Как пользоваться

**Гардероб.** Загружай фото по одному или пачкой. Снимай вещи на однотонном фоне, контрастном по отношению к вещи: белую рубашку — на тёмном, чёрные брюки — на светлом. Фон уберётся сам, цвета определятся автоматически. Перед сохранением проверь категорию и сезоны.

**Студия.** Три кнопки: собрать одну капсулу, собрать сразу серию из всех вещей, собрать вручную. Любой коллаж редактируется — вещь перетаскивается пальцем, меняются размер, наклон и порядок слоёв. Кнопка «Заменить» подставляет другую вещь той же категории.

**Погода.** Введи город один раз — сезон будет подставляться по текущей температуре.

**Аналитика.** Счётчик носки, календарь, вещи-невидимки и подсказки, чего не хватает в гардеробе. Работает точнее, если отмечать «Носила».

**Желания.** Вещи, которых пока нет. В образы не попадают, но видно, сколько новых сочетаний добавит покупка.

## Сколько это стоит

Ничего. Бесплатный тариф Supabase — 500 МБ базы и 1 ГБ на файлы; одна вырезанная вещь весит около 20 КБ, то есть места хватит на десятки тысяч вещей. Vercel бесплатен для личных проектов. Единственное ограничение: если не заходить в Supabase дольше недели, проект засыпает — просто открой панель и нажми **Restore**.

## Если что-то не работает

**Письмо не приходит** — проверь «Спам». Встроенная почта Supabase ограничена несколькими письмами в час; сессия после входа живёт долго, так что запрашивать ссылку каждый день не придётся.

**Ссылка из письма ведёт на localhost** — не выполнен шаг 5.

**Фото не загружается** — скорее всего, не выполнен `schema.sql` целиком: без него нет ни таблиц, ни хранилища.

**Вещь вырезалась криво** — фон совпал по цвету с вещью. Перефотографируй на контрастном фоне.
